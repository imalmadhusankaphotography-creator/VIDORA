VIDORA app icon and wordmark (every image in this directory: filmcraft.svg, filmcraft-small.svg,
filmcraft-1024.png, filmcraft-macos-512.png, filmcraft.icns, filmcraft.ico, hicolor/,
vidora-wordmark-light.png, vidora-wordmark-dark.png; and apps/filmcraft-web/web/favicon.png).
The icon file names are FilmCraft's, kept so the build and packaging scripts find them; the
artwork is VIDORA's.

The VIDORA logo (the V-and-play symbol) was designed by Imal Madhusanka
(packaging/vidora/logo/vidora-logo.png). These files are made from it by
packaging/vidora/make_logo_assets.py; the wordmark lettering is set in Inter Bold (SIL OFL 1.1,
assets/fonts/OFL-Inter.txt).
