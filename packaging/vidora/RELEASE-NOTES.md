**VIDORA** — a Premiere Pro-style video editor for Windows, by Imal Madhusanka. Built on FilmCraft v0.9.0.

### Download (Windows 10/11, 64-bit)

| File | |
|---|---|
| `VIDORA-<version>-windows-x64.msi` | **Installer**: VIDORA in the Start menu and on the desktop |
| `VIDORA-<version>-windows-x64-portable.zip` | **Portable**: unzip, open the `VIDORA` folder, run `VIDORA.exe` |

The files are not code-signed, so Windows may say it protected your PC the first time: choose **More info ▸ Run anyway**.

- පළවෙනි පාර "Windows protected your PC" කියලා ආවොත් **More info › Run anyway** ඔබන්න.
